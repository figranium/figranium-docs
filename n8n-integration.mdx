The official Figranium n8n community node (`n8n-nodes-figranium`) connects n8n workflows to Figranium. Use it to execute saved browser automation tasks, pass runtime variables, and work with tasks, executions, and schedules.

## Install the node

<Steps>
  <Step title="Add Figranium">
    In an n8n workflow, click **Add node**, search for **Figranium**, and select the verified community node.
  </Step>
  <Step title="Install the node">
    Install it when prompted, then add it to your workflow.
  </Step>
  <Step title="Configure credentials">
    Create a **Figranium API** credential with your Figranium **Base URL** and **API key**. Use the base URL without a trailing slash. If you need an API key, see [Get Your Figranium API Key](/api-key).
  </Step>
  <Step title="Choose an operation">
    Select **Execute Task** to run a saved task, or choose one of the task, execution, or schedule operations.
  </Step>
  <Step title="Map variables">
    For task execution, provide runtime variables as name/value pairs. n8n expressions such as `{{ $json.product_url }}` can supply values from earlier nodes.
  </Step>
</Steps>

<Note>
  On self-hosted n8n instances, an instance owner may need to allow or install verified community nodes first.
</Note>

## Operations

The node can execute tasks, create and manage task definitions, list execution history, and manage schedules and scheduler status.

For the underlying endpoints, see the [REST API Reference](/rest-api).

## Runtime variables

Runtime variables let the same Figranium task accept different inputs on every n8n run. Variable names are case-sensitive and must match those defined by the task.

See [Variables & Templating](/variables) for details.

## Authentication

The node authenticates directly with your Figranium instance using the API key in the **Figranium API** credential. Keep the key secret and rotate it if it is exposed. See [API Key](/api-key) for key management.
