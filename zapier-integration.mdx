Figranium Browsers' Zapier integration lets you run browser automation tasks from a Zap and pass runtime variables into them.

## Before you start

You need a running Figranium Browsers instance and an API key. If you do not have a key yet, see [Get Your Figranium Browsers API Key](/api-key).

<Steps>
  <Step title="Add Figranium Browsers to your Zap">
    In Zapier, create or open a Zap and add **Figranium Browsers** as an action app.
  </Step>
  <Step title="Connect your Figranium Browsers instance">
    When prompted, enter your Figranium Browsers **Base URL** and **API key**. Copy the API key from Figranium Browsers **Settings**. Your Base URL is the address you use to reach your Figranium Browsers instance.

    Use the base URL without a trailing slash.
  </Step>
  <Step title="Choose a task">
    Select the Figranium Browsers task you want to execute from the task dropdown.
  </Step>
  <Step title="Add runtime variables">
    If the task uses variables, provide the values you want to override for this run. Leave variables empty when no overrides are needed.
  </Step>
  <Step title="Test and publish">
    Test the action to confirm Figranium Browsers can execute the selected task, then finish configuring and publish your Zap.
  </Step>
</Steps>

## Runtime variables

Runtime variables let the same Figranium Browsers task accept different inputs on each Zap run. Define variables in Browsers, then map data from earlier Zap steps into those variables.

For details on Browsers variables and templating, see [Variables & Templating](/variables).

## Authentication

The integration authenticates directly with your Figranium Browsers instance. Keep your API key private and rotate it if it is exposed. See [API Key](/api-key) for key management instructions.
