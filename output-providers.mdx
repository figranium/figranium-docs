Connect an existing Baserow table to a Figranium task to append extracted results after each run. Create the destination and its fields in Baserow first, then choose them in the task's output settings.

## Overview

After a task finishes extracting data, Figranium can send its JSON result to a configured output destination. For Baserow, each object becomes a row and an array of objects becomes a batch of rows.

## Baserow Integration

[Baserow](https://baserow.io) is a self-hosted, open-source alternative to Airtable. Figranium can append extracted JSON data to a table that you select from the databases and tables available to your saved token.

### Prerequisites

1. A running Baserow instance, either self-hosted or Baserow.io cloud.
2. A Baserow database token with permission to list accessible databases and tables and create rows in the destination table.
3. An existing database, table, and fields that match the task's output.

### Step 1: Configure credentials

You can add a Baserow credential in **Settings > Connections** or from the task editor:

<Steps>
  <Step title="Open the credential form">
    In **Settings > Connections**, go to **Database / Output** and add a credential. Alternatively, open task **Settings > Output** and choose **\+ New** next to the credential selector.
  </Step>
  <Step title="Enter your Baserow details">
    Select **Baserow**, then enter a name, the Baserow base URL (for example, `https://api.baserow.io`), and your API token.
  </Step>
  <Step title="Save the credential">
    Save the credential. Figranium stores it separately from task variables and uses it when sending rows to Baserow.
  </Step>
</Steps>

### Step 2: Select the output destination

<Steps>
  <Step title="Open task output settings">
    Open the task in the editor and go to **Settings > Output**.
  </Step>
  <Step title="Choose Baserow and a credential">
    Select **Baserow**, then select the saved credential that can access your destination.
  </Step>
  <Step title="Choose a database and table">
    Select an existing database, then select a table within it. Figranium lists destinations available to the token. It does not create databases, tables, or fields.
  </Step>
  <Step title="Create matching fields in Baserow">
    Create a field for each key in your extraction output. The task editor shows known output fields that are missing from the selected table. If you use a JavaScript extraction script and have no sample output yet, run the task once to identify the fields.
  </Step>
  <Step title="Choose error behavior and save">
    Set **On Push Error** to `ignore` (default) or `fail`, then save the task. `fail` marks the execution as failed if the Baserow push fails.
  </Step>
</Steps>

### Return data that matches your table

Figranium uses Baserow's `user_field_names=true` option. Object keys in your extraction result must match the field names in the selected table exactly, including capitalization.

Return a single object to insert one row:

```js
return {
  "Product Name": "Widget Pro",
  "Price": 29.99,
  "In Stock": true,
  "URL": window.location.href
};
```

Return an array of objects to insert multiple rows:

```js
const rows = Array.from(document.querySelectorAll(".product-card")).map(card => ({
  "Product Name": card.querySelector(".title")?.innerText.trim(),
  "Price": parseFloat(card.querySelector(".price")?.innerText.replace("$", "")),
  "URL": card.querySelector("a")?.href
}));

return rows;
```

Each returned object becomes a row. Nested objects and arrays are serialized as JSON text. The table must already have compatible fields for every key.

### How data is sent

| Extracted data shape | Baserow API operation |
| :-- | :-- |
| JSON object `{}` | Create one row in the selected table |
| JSON array `[{}, {}]` | Batch-create rows in the selected table |

Figranium authenticates with `Authorization: Token <your-token>`.

### Error handling

By default, output push failures are ignored so a temporary Baserow issue does not fail the task. Set **On Push Error** to `fail` if the execution should fail when the push fails. Check the execution logs for the output push status.

<Note>
  Figranium validates Baserow URLs and redirect destinations to help prevent requests to private or internal network addresses. See [Security best practices](/security) for details.
</Note>
