This guide is for developers who want to run Figranium's source code directly on their machine for modification or testing, without using Docker.

## Prerequisites

- **Node.js**: Version 18 (LTS) or higher.
- **pnpm**: Recommended package manager.
- **Playwright**: Dependencies must be installed on your OS.

## Setup Steps

<Steps>
  <Step title="Clone the Repository">
    ```bash
    git clone https://github.com/figranium/figranium.git
    cd figranium
    ```
  </Step>
  <Step title="Install Dependencies">
    <CodeGroup>

    ```bash pnpm
    pnpm install
    ```

    ```bash npm
    npm install
    ```

    ```bash yarn
    yarn install
    ```

    </CodeGroup>
  </Step>
  <Step title="Install Playwright Browsers">
    ```bash
    npx playwright install chromium
    ```
  </Step>
  <Step title="Environment Setup">
    Create a `.env` file in the root directory (refer to the [Configuration](/configuration) page for available variables). At minimum, set:

    ```bash
    SESSION_SECRET=your_random_secret_here
    ```
  </Step>
  <Step title="Start the Application">
    You need to run both the backend server and the frontend development server simultaneously:

    **Backend:**

    ```bash
    pnpm run server
    ```

    **Frontend:**

    ```bash
    pnpm run dev
    ```

    The frontend will be available at `http://localhost:5173`, and it will proxy API requests to the backend at `http://localhost:11345`.
  </Step>
  <Step title="(Optional) Start the CAPTCHA Solver">
    If you plan to use the `solve_captcha` action or the task-level auto-solve setting, start the bundled `ohmycaptcha` sidecar in a third terminal:

    ```bash
    pnpm run captcha:dev
    ```

    This resolves a Python 3.10\+ interpreter, installs `ohmycaptcha` into an isolated virtualenv, and starts the solver on `127.0.0.1:8000`. The Docker image starts this automatically via `entrypoint.sh`; the source-based workflow does not, so `solve_captcha` blocks fail with a connection error until you run this command. See [CAPTCHA Solving](/captcha-solving) for details.
  </Step>
</Steps>

## Building for Production

To create a production build:

```bash
pnpm run build
```

This generates a `dist/` folder with optimized assets. You can then run the server in production mode:

```bash
NODE_ENV=production pnpm run server
```
