Deploy Figranium Browsers on your own DigitalOcean Droplet with the official 1-Click App.

The image comes preconfigured with Docker, Figranium Browsers, Caddy, and an automatic updater, so you can go from a new Droplet to a working visual browser automation environment without manually installing the application stack.

## Deploy

<Steps>
  <Step title="Create a Figranium Browsers Droplet">
    Open the Figranium Browsers listing in the DigitalOcean Marketplace and create a Droplet from the 1-Click App.
  </Step>
  <Step title="Choose your Droplet size">
    Use at least 2 GB of RAM for typical workloads. For heavier browser tasks or concurrent executions, 4 GB or more is recommended.
  </Step>
  <Step title="Wait for provisioning">
    DigitalOcean will create the Droplet and start the preconfigured Figranium Browsers environment automatically.
  </Step>
</Steps>

<Note>
  See [Host Specs](/host-specs) for more detailed resource guidance.
</Note>

## Getting Started

Your Figranium Browsers instance is ready to use after the Droplet finishes provisioning.

<Steps>
  <Step title="Open Figranium Browsers">
    Visit:

    ```text
    http://your_droplet_public_ipv4
    ```

    Caddy is preconfigured as a reverse proxy, so you do not need to specify Figranium Browsers' internal application port.

    On your first visit, create your administrator account and sign in.
  </Step>
  <Step title="Create your first automation">
    From the dashboard, create a new task and use Figranium Browsers' visual editor to build your browser workflow.

    You can automate navigation, clicks, typing, data extraction, screenshots, JavaScript, and other browser interactions.
  </Step>
  <Step title="Use the API">
    Figranium Browsers includes a REST API for executing tasks and connecting your instance to external applications, AI agents, and workflow automation platforms.

    Your API key is available from Figranium Browsers' settings after signing in.

    <Card title="REST API" icon="code" href="/rest-api">
      Learn how to execute and manage Figranium Browsers programmatically.
    </Card>
  </Step>
</Steps>

## Automatic updates

The DigitalOcean deployment keeps Figranium Browsers current automatically.

<Tip>
  The updater runs shortly after boot and then checks once per hour for a newer stable Figranium Browsers container image.
</Tip>

When a newer image is available, Docker pulls it and recreates the Figranium Browsers service using the updated image. If the deployed image is already current, the running container is left unchanged.

Persistent application data and captures are stored outside the application container and are preserved when Figranium Browsers is updated.

## Custom domain and HTTPS

You can optionally serve Figranium Browsers from your own domain or subdomain and let Caddy manage HTTPS automatically.

<Steps>
  <Step title="Point your domain to the Droplet">
    Create an `A` record with your DNS provider that points your domain or subdomain to:

    ```text
    your_droplet_public_ipv4
    ```
  </Step>
  <Step title="Edit the Caddy configuration">
    SSH into the Droplet and edit:

    ```text
    /etc/caddy/Caddyfile
    ```

    Replace the default configuration with:

    ```caddyfile
    your-domain.example.com {
        reverse_proxy 127.0.0.1:11345
    }
    ```
  </Step>
  <Step title="Allow HTTPS traffic">
    ```bash
    sudo ufw allow 443/tcp
    ```
  </Step>
  <Step title="Validate and reload Caddy">
    ```bash
    sudo caddy validate --config /etc/caddy/Caddyfile
    sudo systemctl reload caddy
    ```
  </Step>
</Steps>

Once the DNS record resolves to the Droplet, Caddy automatically provisions and renews an HTTPS certificate for the domain.

Your Figranium Browsers instance will then be available at:

```text
https://your-domain.example.com
```

<Warning>
  Do not expose Figranium Browsers publicly without completing the initial administrator setup and reviewing your instance's security configuration.
</Warning>

## Connect a PostgreSQL database

By default, Figranium Browsers stores data in files on the Droplet. To use a PostgreSQL database instead, such as a DigitalOcean Managed Database, set the connection details as environment variables on the Figranium Browsers service and restart it. Figranium Browsers accepts lowercase names such as `db_host`, `db_port`, `db_username`, `db_password`, `db_database`, and `db_ssl`, alongside the standard uppercase variables.

```bash
db_host=your-cluster.db.ondigitalocean.com
db_port=25060
db_username=doadmin
db_password=your_database_password
db_database=defaultdb
db_ssl=true
```

<Note>
  PostgreSQL connection details are configured with environment variables only, not from the Settings page. See [PostgreSQL Support](/database-support#alternative-variable-names) for every accepted variable name.
</Note>
