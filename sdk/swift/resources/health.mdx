The `HealthResource` on `client.health` provides a lightweight liveness probe for any Figranium instance. Call `check()` to confirm the server is up, read its version, and verify that your SDK install and network path are working. No API key is required.

## Client setup

```swift HealthResource.swift
import Figranium

let client = Figranium()
```

## Methods

<AccordionGroup>
  <Accordion title="`check`">
    ```swift
    check(options: RequestOptions = .init()) async throws -> HealthStatus
    ```

    Performs a `GET /api/health` request and returns the server's health status. This is the fastest way to verify connectivity and SDK configuration.

    ### Returns

    `HealthStatus` with these fields:

    - `status`: a human-readable status string such as `"ok"`
    - `version`: the running Figranium server version

    ### Example: verify connectivity

    ```swift health_check.swift
    let status = try await client.health.check()
    print(status.status)   // "ok"
    print(status.version)  // "0.14.4"
    ```

    ### Example: no authentication needed

    Because `check()` requires no authentication, you can call it before the user has signed in or provided an API key:

    ```swift health_no_auth.swift
    let client = Figranium(baseURL: "https://figranium.example")
    let status = try await client.health.check()
    print(status.status)
    ```

    ### Example: handle transport failures

    Wrap `check()` in a `do/catch` to detect network or DNS issues. Transport failures surface as [`FigraniumError`](/sdk/swift/errors) with `code: "NETWORK_ERROR"`:

    ```swift health_transport.swift
    let client = Figranium(baseURL: "https://figranium.example")
    
    do {
        let status = try await client.health.check()
        print("Server is up:", status.status)
    } catch let error as FigraniumError {
        if error.code == "NETWORK_ERROR" {
            print("Cannot reach the Figranium server. Check the baseURL and network.")
        }
        throw error
    }
    ```

    <Note>
      The `check()` method accepts the standard `RequestOptions` as its `options` argument, so you can pass custom `headers` or a per-request `timeout` when needed.
    </Note>
  </Accordion>
</AccordionGroup>
