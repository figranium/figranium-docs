The Figranium Kotlin SDK is the official Kotlin client for the Figranium API. It is built on Kotlin coroutines, ships with `kotlinx.serialization` models for tasks and actions, and exposes execution streams as `Flow`. The SDK supports Android projects (API 23+) and also runs on the JVM. An optional `figranium-appfunctions` artifact adds Android AppFunctions integration for system assistants and agents (Android API 36+).

## Highlights

<CardGroup cols={2}>
  <Card title="Native Kotlin coroutines" icon="brand-kotlin">
    Every method is `suspend`. Execution and selector streams surface as `Flow<StreamEvent<JsonElement>>` that you collect with standard flow operators.
  </Card>

  <Card title="Type-safe serialization" icon="text-size">
    All request and response models use `kotlinx.serialization`. The SDK serializes and deserializes JSON automatically so you work with typed Kotlin classes.
  </Card>

  <Card title="Custom OkHttp client" icon="plug">
    Pass your own `OkHttpClient` for custom interceptors, certificate pinning, or test doubles. The SDK respects the caller-supplied client.
  </Card>

  <Card title="Cancellable streams" icon="cloud-x">
    Cancelling the collecting coroutine cancels the underlying stream. `executions.watch(executionId, intervalMillis)` polls and emits only on status change, finishing when the run ends.
  </Card>
</CardGroup>

## What you can do with the SDK

- Save, update, version, and roll back tasks with typed `Task` and `Action` values.
- Run tasks with runtime variables, or call `scrape`, `agent`, and `headful` directly for one-off executions.
- Stream live execution events and headful selector events as `Flow`.
- Manage schedules, captures, cookies, and Cabinets.
- Select a per-task Cabinet for intercepted downloads and build typed upload actions.
- Open and inspect headful browser sessions.
- Expose approved Figranium tasks to Android system assistants via AppFunctions (optional).
