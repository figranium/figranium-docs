---

The `credentials` resource on the Figranium Kotlin SDK manages named credential sets used by tasks for external integrations. You can list, create, update, and delete credentials, and you can proxy Baserow requests through a stored credential to list databases and tables without handling tokens manually.

```kotlin main.kt
import dev.figranium.sdk.Figranium

val client = Figranium(
    authentication = FigraniumAuthentication.ApiKey(System.getenv("FIGRANIUM_API_KEY")),
)
```

## Methods

<AccordionGroup>
  <Accordion title="`list`">
    List all stored credentials.

    - **HTTP endpoint:** `GET /api/credentials`
    - **Signature:** `credentials.list(options: RequestOptions = RequestOptions()): List<Credential>`

    ```kotlin list_credentials.kt
    val credentials = client.credentials.list()
    for (credential in credentials) {
        println("${credential.id} ${credential.name} ${credential.provider}")
    }
    ```
  </Accordion>

  <Accordion title="`create`">
    Create a new credential.

    - **HTTP endpoint:** `POST /api/credentials`
    - **Signature:** `credentials.create(input: CredentialInput, options: RequestOptions = RequestOptions()): Credential`

    ```kotlin create_credential.kt
    val input = CredentialInput(
        name = "Production Baserow",
        provider = "baserow",
        config = mapOf("apiUrl" to "https://api.baserow.io", "token" to "my-token")
    )
    val credential = client.credentials.create(input)
    println(credential.id)
    ```
  </Accordion>

  <Accordion title="`update`">
    Update an existing credential in place.

    - **HTTP endpoint:** `PUT /api/credentials/{credentialId}`
    - **Signature:** `credentials.update(id: String, input: CredentialInput, options: RequestOptions = RequestOptions()): Credential`

    ```kotlin update_credential.kt
    val input = CredentialInput(
        name = "Production Baserow",
        provider = "baserow",
        config = mapOf("apiUrl" to "https://api.baserow.io", "token" to "new-token")
    )
    val credential = client.credentials.update("cred_01", input)
    println(credential.id)
    ```
  </Accordion>

  <Accordion title="`delete`">
    Delete a credential.

    - **HTTP endpoint:** `DELETE /api/credentials/{credentialId}`
    - **Signature:** `credentials.delete(id: String, options: RequestOptions = RequestOptions()): JsonObject`

    ```kotlin delete_credential.kt
    val result = client.credentials.delete("cred_01")
    ```
  </Accordion>

  <Accordion title="`baserowDatabases`">
    List Baserow databases through a stored credential. The server proxies the request using the credential's token.

    - **HTTP endpoint:** `GET /api/credentials/{credentialId}/proxy/baserow/databases`
    - **Signature:** `credentials.baserowDatabases(id: String, options: RequestOptions = RequestOptions()): JsonObject`

    ```kotlin baserow_databases.kt
    val result = client.credentials.baserowDatabases("cred_01")
    ```
  </Accordion>

  <Accordion title="`baserowTables`">
    List tables inside a Baserow database through a stored credential.

    - **HTTP endpoint:** `GET /api/credentials/{credentialId}/proxy/baserow/databases/{databaseId}/tables`
    - **Signature:** `credentials.baserowTables(id: String, databaseId: String, options: RequestOptions = RequestOptions()): JsonObject`

    ```kotlin baserow_tables.kt
    val result = client.credentials.baserowTables("cred_01", databaseId = "db_123")
    ```
  </Accordion>
</AccordionGroup>

## Models

### `CredentialInput`

```kotlin
@Serializable
data class CredentialInput(
    val name: String,
    val provider: String = "baserow",
    val config: Map<String, String>
)
```

### `Credential`

```kotlin
@Serializable
data class Credential(
    val id: String,
    val name: String,
    val provider: String,
    val config: Map<String, String>
)
```
