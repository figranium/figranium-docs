The `AuthResource` on `client.auth` handles session-based authentication. Use it to check whether the server is already configured, create the first admin account, log in with email and password, log out, and inspect the currently authenticated user. These methods pair naturally with `Session` authentication, which relies on OkHttp's cookie jar instead of API keys.

```kotlin
import dev.figranium.sdk.Figranium
import dev.figranium.sdk.FigraniumAuthentication

val client = Figranium(
    authentication = FigraniumAuthentication.Session,
)
```

<Note>
  Session authentication uses OkHttp's cookie jar. After a successful `login` call, subsequent requests on the same `OkHttpClient` automatically include the session cookie. Create the client with `FigraniumAuthentication.Session` and a shared or custom `OkHttpClient` to preserve cookies across calls.
</Note>

## Methods

<AccordionGroup>
  <Accordion title="`checkSetup`">
    Checks whether the Figranium server has been set up with an initial admin account.

    - **HTTP endpoint:** `GET /api/auth/check-setup`
    - **Signature:** `checkSetup(options: RequestOptions = RequestOptions()): JsonObject`
    - **Returns:** `JsonObject` containing `setupComplete` as a boolean.

    ```kotlin check_setup.kt
    import kotlinx.serialization.json.*
    
    val result = client.auth.checkSetup()
    val complete = result["setupComplete"]?.jsonPrimitive?.booleanOrNull
    println("Server configured: $complete")
    ```
  </Accordion>

  <Accordion title="`setup`">
    Creates the initial admin account on a fresh Figranium server. This can only be called when `checkSetup` returns `setupComplete: false`.

    - **HTTP endpoint:** `POST /api/auth/setup`
    - **Signature:** `setup(name: String, email: String, password: String, options: RequestOptions = RequestOptions()): JsonObject`
    - **Returns:** `JsonObject` with user details and session information.

    ```kotlin setup.kt
    val result = client.auth.setup(
        name = "Admin",
        email = "admin@example.com",
        password = "secure-password",
    )
    println(result)
    ```
  </Accordion>

  <Accordion title="`login`">
    Authenticates with email and password, establishing a session cookie for subsequent requests.

    - **HTTP endpoint:** `POST /api/auth/login`
    - **Signature:** `login(email: String, password: String, options: RequestOptions = RequestOptions()): JsonObject`
    - **Returns:** `JsonObject` with user details and session information.

    ```kotlin login.kt
    val result = client.auth.login(
        email = "admin@example.com",
        password = "secure-password",
    )
    println(result)
    ```
  </Accordion>

  <Accordion title="`logout`">
    Ends the current session and invalidates the session cookie.

    - **HTTP endpoint:** `POST /api/auth/logout`
    - **Signature:** `logout(options: RequestOptions = RequestOptions()): JsonObject`
    - **Returns:** `JsonObject`

    ```kotlin logout.kt
    val result = client.auth.logout()
    println(result)
    ```
  </Accordion>

  <Accordion title="`me`">
    Returns the currently authenticated user's profile.

    - **HTTP endpoint:** `GET /api/auth/me`
    - **Signature:** `me(options: RequestOptions = RequestOptions()): JsonObject`
    - **Returns:** `JsonObject` with `id`, `name`, `email`, and other user fields.

    ```kotlin me.kt
    val user = client.auth.me()
    val email = user["email"]?.jsonPrimitive?.contentOrNull
    println("Logged in as: $email")
    ```
  </Accordion>
</AccordionGroup>

## Session authentication workflow

A typical session-based workflow checks setup status, creates or logs into an account, then performs authenticated operations on other resources.

```kotlin session_workflow.kt
val client = Figranium(
    authentication = FigraniumAuthentication.Session,
)

// 1. Check if the server needs initial setup
val setupStatus = client.auth.checkSetup()
val setupComplete = setupStatus["setupComplete"]?.jsonPrimitive?.booleanOrNull
if (setupComplete == false) {
    client.auth.setup(
        name = "Admin",
        email = "admin@example.com",
        password = "secure-password",
    )
}

// 2. Log in
client.auth.login(
    email = "admin@example.com",
    password = "secure-password",
)

// 3. Verify the session
val user = client.auth.me()
println(user)

// 4. Use other resources with the same session
val tasks = client.tasks.list()
println(tasks.size)

// 5. Log out when finished
client.auth.logout()
```
