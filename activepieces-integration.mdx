The Figranium piece for Activepieces lets you run saved browser automation tasks, inspect executions, and manage schedules from Activepieces flows.

## Install the piece

In Activepieces, open **Platform Admin → Pieces → Install Piece**.

Choose **NPM Registry**, then enter:

- **Piece Name:** `@figranium/piece`
- **Piece Version:** `0.0.1`

Click **Install**. Once installed, the Figranium piece will be available in the flow builder.

## Connect Figranium

Create a Figranium connection with:

- **Base URL** — the URL of your Figranium server.
- **API Key** — your Figranium API key.

The piece loads saved tasks from Figranium so actions such as **Execute Task** can show a Task dropdown.

<Warning>
The Activepieces server loads dynamic data such as the Task dropdown. The request comes from the Activepieces server, not directly from your browser.
</Warning>

Your Figranium Base URL therefore needs to be reachable **from the machine or container running Activepieces**. In the common case where Figranium and Activepieces are hosted on separate servers, use the normal network-accessible URL for your Figranium instance.

## Available actions

The piece includes actions to execute tasks, list tasks and executions, list and manage schedules, inspect scheduler status, preview schedule configurations, and make custom Figranium API calls.
