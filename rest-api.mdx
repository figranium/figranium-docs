---
title: "REST API Reference"
---

Figranium exposes a local REST API for task management, execution, and data retrieval.

**Base URL**: `http://localhost:11345` (default)

## **Authentication**

If enabled, authentication must be provided via one of the following methods:

-   **Header**: `x-api-key: your_key` or `key: your_key`
-   **Authorization Header**: `Authorization: Bearer your_key`
-   **Request Body**: `{"apiKey": "your_key"}` or `{"key": "your_key"}`

## **Tasks**

### `GET /api/tasks`

Lists all saved tasks.

**Response**:

```text
[
  {
    "id": "task_1",
    "name": "Scraper",
    "url": "https://example.com"
  }
]
```

### `POST /api/tasks`

Creates a new task.

**Body**:

```text
{
  "name": "New Task",
  "url": "https://example.com",
  "mode": "agent",
  "actions": []
}
```

### `POST /api/tasks/:id/api`

Triggers an execution of a specific task.

**Body**:

```text
{
  "variables": {
    "query": "override value"
  }
}
```

**Response**: Returns the execution result (JSON).

## **Executions**

### `GET /api/executions`

Lists execution history.

**Query Parameters**:

- `limit`: Number of results (default 50).
- `status`: Filter by status code.

### `GET /api/executions/:id`

Gets detailed logs and result for a specific execution.

## **Data**

### `GET /api/data/captures`

Lists all captured files (screenshots, recordings).

### `DELETE /api/data/captures/:name`

Deletes a specific capture file.

## **Settings**

### `GET /api/settings/proxies`

Lists configured proxies.

### `POST /api/settings/proxies`

Adds a new proxy.

**Body**:

```text
{
  "server": "http://1.2.3.4:8080",
  "label": "US Proxy"
}
```

### `POST /api/settings/api-key`

Generates/regenerates the API key.

## **Schedules**

### `GET /api/schedules`

Lists all tasks that have an associated schedule configuration.

**Response**:

```json
{
  "schedules": [
    {
      "taskId": "c1f7a08b",
      "taskName": "Daily Price Check",
      "mode": "agent",
      "schedule": {
        "enabled": true,
        "frequency": "daily",
        "hour": 9,
        "minute": 0,
        "nextRun": 1690099200000,
        "lastRun": 1690012800000,
        "lastRunStatus": "success",
        "lastRunDurationMs": 15400
      }
    }
  ]
}
```

### `POST /api/schedules/:taskId`

Creates or updates a schedule for a task.

**Body (Visual/No-code)**:

```json
{
  "enabled": true,
  "frequency": "daily",
  "hour": 9,
  "minute": 0
}
```

**Body (Advanced/Cron)**:

```json
{
  "enabled": true,
  "cron": "0 9 * * 1-5"
}
```

**Response**:

```json
{
  "schedule": { ... },
  "description": "Every day at 9:00 AM",
  "nextRun": 1690099200000
}
```

### `DELETE /api/schedules/:taskId`

Disables the schedule for a task.

**Response**:

```json
{ "success": true }
```

### `GET /api/schedules/:taskId/status`

Gets detailed schedule status and validation for a specific task.

**Response**:

```json
{
  "schedule": { ... },
  "cron": "0 9 * * *",
  "description": "Every day at 9:00 AM",
  "isValid": true
}
```

### `POST /api/schedules/:taskId/describe`

Validates and describes a schedule configuration without saving it. Useful for UI previews.

**Body**: Same as `POST /api/schedules/:taskId`.

**Response**:

```json
{
  "valid": true,
  "cron": "0 9 * * *",
  "description": "Every day at 9:00 AM",
  "nextRun": 1690099200000
}
```

### `GET /api/schedules/status/all`

Returns the runtime status of the global scheduler and all currently active jobs.

**Response**:

```json
{
  "running": true,
  "scheduledCount": 2,
  "tasks": [
    {
      "taskId": "c1f7a08b",
      "cron": "0 9 * * *",
      "nextRun": "2024-07-23T09:00:00.000Z",
      "nextRunMs": 1721725200000
    }
  ]
}
```
