The Folate repository includes scripts to rebuild the model from scratch on `osunlp/Mind2Web`.

```bash
git clone https://github.com/figranium/folate
cd folate
python -m pip install -r requirements-train.txt

# 1. Stream and serialize Mind2Web pairs
python scripts/prepare_data.py --output-dir ./data

# 2. Fine-tune the ELECTRA cross-encoder
python scripts/train.py --data-dir ./data --save-dir ./folate-base

# 3. Export to FP32 ONNX and quantize to INT8 (~107 MB)
python scripts/export_onnx.py --model-dir ./folate-base --output-dir ./folate-int8

# 4. Evaluate the Mind2Web test splits
python scripts/eval_mind2web.py --confidence-threshold 0.5 --json-out mind2web_results.json

# 5. Run the Playwright DOM-resolved selector precision and recall benchmark
python scripts/eval_precision.py --confidence-threshold 0.5 --json-out precision_results.json
```

## Scripts

| Script | Purpose |
| :--- | :--- |
| `prepare_data.py` | Streaming Mind2Web serializer (`lxml`). |
| `train.py` | Fine-tuning (bf16, fp16, or CPU). |
| `export_onnx.py` | FP32 ONNX export and INT8 dynamic quantization. |
| `eval_mind2web.py` | Mind2Web evaluator: precision, recall, F1, Top-1/3/5, and MRR. |
| `eval_precision.py` | Playwright benchmark of DOM-resolved selector precision and recall. |

See [Benchmarks](/folate/benchmarks) for published results.
