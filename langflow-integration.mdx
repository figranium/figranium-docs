Figranium Browsers integrates with LangFlow so browser automation can become part of a visual LangFlow flow. Configure your Browsers connection, select a task, and feed dynamic values into the task from other components.

## Set up Figranium Browsers in LangFlow

<Steps>
  <Step title="Add Figranium Browsers to a flow">
    In LangFlow, find the **Figranium Browsers** component and add it to your flow.
  </Step>
  <Step title="Configure the connection">
    Enter your Figranium Browsers **Base URL** and **API key** in the component configuration. Copy the API key from Figranium Browsers **Settings**. Your Base URL is the address you use to reach your Figranium Browsers instance.

    Use the base URL without a trailing slash. If you need to create a key, see [Get Your Figranium Browsers API Key](/api-key).
  </Step>
  <Step title="Select a task">
    Choose the Figranium Browsers task the component should run.
  </Step>
  <Step title="Provide variables">
    Supply runtime variables when the task needs dynamic input. Connect values from other LangFlow components or provide them directly.
  </Step>
  <Step title="Run the flow">
    Execute the flow. LangFlow invokes the selected Figranium Browsers task using the configured connection and inputs.
  </Step>
</Steps>

## Runtime variables

Use variables to connect LangFlow data to reusable Figranium Browsers automations. A flow can pass values such as URLs, queries, or identifiers into a task at execution time.

See [Variables & Templating](/variables) for details.

## Authentication

The component uses your Figranium Browsers API key to authenticate with your instance. Keep the key secret and rotate it if necessary. See [API Key](/api-key) for key management instructions.
