The Dify plugin brings Figranium Browsers browser automation into Dify workflows and applications. Connect your Figranium Browsers instance, choose a task, and pass structured runtime variables from Dify into each run.


## Install the plugin

<Steps>
  <Step title="Install Figranium Browsers">
    Open the [Figranium Browsers plugin on the Dify Marketplace](https://marketplace.dify.ai/plugin/figranium/figranium) and install it.
  </Step>
  <Step title="Configure credentials">
    Add your Figranium Browsers **Base URL** and **API key** when configuring the plugin. Copy the API key from Figranium Browsers **Settings**. Your Base URL is the address you use to reach your Figranium Browsers instance.

    Use the base URL without a trailing slash. If you need an API key, see [Get Your Figranium Browsers API Key](/api-key).
  </Step>
  <Step title="Add a Figranium Browsers tool">
    Add the Figranium Browsers tool to your Dify workflow or application.
  </Step>
  <Step title="Choose a task">
    Select the Figranium Browsers task to execute from the available tasks.
  </Step>
  <Step title="Map variables">
    Provide runtime variables as key-value data when the task needs dynamic inputs. Values can come from user input or previous Dify nodes.
  </Step>
</Steps>

## Runtime variables

Browsers task variables make one automation reusable across many Dify runs. For example, a Dify workflow can supply a URL, search term, customer ID, or other value without changing the underlying Figranium Browsers task.

See [Variables & Templating](/variables) for the Figranium Browsers variable syntax and behavior.

## Authentication

The plugin connects to the Figranium Browsers instance you configure. Treat the API key as a secret and rotate it if it becomes exposed. See [API Key](/api-key) for key management.
