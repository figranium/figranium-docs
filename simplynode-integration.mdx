# SimplyNode × Figranium Integration

## SimplyNode overview

SimplyNode is a residential and mobile proxy provider with 50M+ residential IPs and 1.4M+ mobile IPs across 185+ countries, with no bandwidth expiration on purchased traffic. It is built for teams running high-volume, geo-sensitive, or detection-sensitive connections.

## How SimplyNode integrates with Figranium

Figranium workflows run through a browser engine that may need a clean, rotating, or sticky IP depending on the task. A proxy layer like SimplyNode plugs directly into that need.

Because Figranium has native proxy import with HTTP/SOCKS5 support, round-robin or random rotation, and credential support, you can bring a SimplyNode proxy pool directly into Figranium without hand-managing individual proxy entries. Generate your proxies in SimplyNode, import them into Figranium, and manage the pool from Figranium.

## Use cases and technical details

- **Data extraction and scraping tasks** — set rotation to **new IP for each request** for high-volume scrape jobs where IP consistency does not matter.
- **Price and change monitoring** — scheduled or cron tasks can use timed rotation, such as a fresh IP every hour, to reduce rate-limiting or repeated fingerprint patterns across visits to the same site.
- **Lead enrichment workflows** — target by country, region, city, or ISP when collecting region-specific public data.
- **QA and regression testing** — sticky sessions keep one IP for the full run duration so a multi-step flow does not switch IPs mid-task.
- **Traffic-based proxy profiles** — allocate GB per project, GEO, or platform so usage and billing stay separated across different Figranium workflows.
- **Residential vs mobile** — SimplyNode offers residential and mobile traffic from \$2.25/GB at scale. Mobile IPs are useful for platforms with aggressive datacenter or residential detection.
- **No bandwidth expiration** — useful for workflows with irregular or bursty usage, such as scheduled tasks that only spike during monitoring windows.

## Getting started: setting up proxies in SimplyNode

Before connecting to Figranium, you need a SimplyNode account with traffic and a proxy profile set up.

### Step 1: Choose your traffic type

SimplyNode offers two pools:

- **Residential (\$2.25/GB at scale)** — IPs from residential ISPs, suited to general-purpose scraping, automation, and platforms with moderate detection.
- **Mobile (\$2.25/GB at scale)** — IPs from mobile carrier networks, recommended for platforms with more aggressive datacenter or residential fingerprint detection.

Choose based on how strict the target platform's detection is. If residential IPs are flagged, mobile is the fallback.

### Step 2: Purchase traffic

Buy the amount of GB you need for your use case. Purchased traffic goes into your **Remaining Traffic** balance, which is your main account balance and is not tied to a single profile yet.

Traffic does not expire, so you can buy in bulk without worrying about monthly resets.

### Step 3: Create a Proxy Profile

From your SimplyNode dashboard, click **Add Proxy Profile**, then:

1. Allocate the amount of traffic in GB that you want to assign to this profile from your main balance.
2. Name the profile. Useful conventions include project, GEO, or platform/use case, such as **Figranium — Scraping** or **Figranium — QA**.

You can create multiple profiles and split traffic across them, which is useful if you run several Figranium workflows and want separate usage tracking or team access per profile.

### Step 4: Generate your proxy list

Open the profile to access the **Proxy List Generator**, where you can configure and generate your proxies. The Figranium-specific settings are covered below.

## Configuring your SimplyNode proxies in Figranium

Figranium can import the proxy list generated by SimplyNode directly, so you do not need to enter individual proxy credentials manually.

### Step 1: Configure your proxies in SimplyNode

Open the **Proxy List Generator** for your SimplyNode proxy profile and configure the GEO, rotation, session, and other proxy settings for your workflow.

When choosing the proxy format, select **HTTP**, **HTTPS**, or **SOCKS5** from the dropdown rather than using a custom format.

- For tasks that need a new IP on every run, such as scraping or data extraction, set rotation to **new IP for each request**.
- For tasks that need one IP throughout, such as QA flows or multi-step sessions, use a **sticky session** with a fixed session ID. The same session ID returns the same IP, while a new session ID returns a new one.

### Step 2: Download the proxy list

Once you have configured the proxies, download the generated proxy list as a **TXT file** from SimplyNode.

### Step 3: Import the proxy list into Figranium

1. Open Figranium.
2. Navigate to **Settings > Proxies**.
3. Import the **TXT file** you downloaded from SimplyNode.

The generated SimplyNode proxy will now appear in your Figranium proxy list.

### Step 4: Mark it as a rotating pool

SimplyNode provides a pool of IP addresses rather than a single fixed IP. After importing the proxy:

1. Find the imported proxy in **Settings > Proxies** and click **Edit**.
2. Check **Rotating Pool**.
3. Click **Save**.

This tells Figranium that the proxy represents a rotating pool of IP addresses rather than a single IP address.

Your SimplyNode proxy is now configured and ready to use with Figranium workflows.
